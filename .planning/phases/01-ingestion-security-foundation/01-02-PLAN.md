<objective>
Implement the Google OAuth2 flow endpoints. `/login` initiates the authorization workflow using the user's Telegram ID as the state (implementing D-07), and `/callback` exchanges the authorization code, encrypts the credentials using the AES-256 Fernet utility, stores them in PostgreSQL mapped to the Telegram chat ID (implementing D-08), and redirects to a callback success page. Implement the Google OIDC JWT validation helper for securing the Pub/Sub webhook (implementing SEC-01).

Purpose: Establish the secure credentials exchange and signature validation systems.
Output: OAuth callback router endpoints, mock tests, and JWT validation utilities.
</objective>
