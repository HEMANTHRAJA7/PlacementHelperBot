# Requirements: Placement Sentinel (v1.0 Archived)

**Defined:** 2026-06-08
**Core Value:** Ensure VIT students never miss critical placement updates through secure, real-time AI-powered Telegram notifications, with zero persistent storage of sensitive email content.

## v1 Requirements

### Ingestion & Security Foundation (INGST)

- [x] **INGST-01**: User can authenticate via Gmail OAuth2 and link their VIT student account.
- [x] **INGST-02**: System registers a Gmail Watch API subscription for the linked mailbox.
- [x] **INGST-03**: FastAPI Webhook endpoint captures push notifications from Google Cloud Pub/Sub.
- [x] **INGST-04**: Webhook endpoint immediately enqueues raw mailbox events into Redis/Celery queue.
- [x] **INGST-05**: System uses Redis keys to verify event idempotency, ignoring duplicate Pub/Sub messages.
- [x] **INGST-06**: Celery workers implement retry mechanisms with exponential backoff and route failed jobs to a Dead-Letter Queue (DLQ).
- [x] **INGST-07**: Background task automatically renews the Gmail Watch subscription daily.
- [x] **INGST-08**: System monitors Gmail Watch status and logs alerts for watches nearing expiration.

### Processing, AI Gateway, & Telegram Bot (PROC)

- [x] **PROC-01**: Celery worker retrieves email body, subject, and attachments via Gmail API in the background.
- [x] **PROC-02**: System runs a local deterministic pre-check on email text for student identifiers (Register Number, NeoPAT ID, Email, Name) before calling LLM.
- [x] **PROC-03**: Centralized AI Gateway parses email using Gemini Flash, returning structured JSON matching a Pydantic schema.
- [x] **PROC-04**: AI Gateway classifies email type (PLACEMENT_OPPORTUNITY, INTERNSHIP, ASSESSMENT, SHORTLIST, INTERVIEW, OFFER, REJECTION, OTHER).
- [x] **PROC-05**: AI Gateway extracts metadata (Company Name, Role, Package, Deadline, Event Type, Application Link).
- [x] **PROC-06**: AI Gateway handles prompt versioning, JSON schema validation, cost tracking, retries, and rate limiting.
- [x] **PROC-07**: Unidirectional Telegram Bot dispatcher sends formatted alerts containing parsed company and link info.
- [x] **PROC-08**: Notification priority engine maps alerts (Offer > Shortlist > Interview > Assessment > Opportunity) with custom visual stylings.

### Hybrid Attachment Processing & Matching (MATCH)

- [x] **MATCH-01**: System parses Excel/XLSX attachments deterministically using python parser (pandas/openpyxl) to search for user identifiers.
- [x] **MATCH-02**: System parses PDF attachments deterministically using python parser (pdfplumber) to search for user identifiers.
- [x] **MATCH-03**: System runs local OCR on Image attachments to extract text and match identifiers.
- [x] **MATCH-04**: System falls back to Gemini Vision API for multimodal table matching and reasoning ONLY when deterministic parsing fails.

### Security, Privacy & Monitoring (SEC)

- [x] **SEC-01**: Webhook listener validates incoming Pub/Sub HTTP POST request using Google OIDC JWT signatures.
- [x] **SEC-02**: DB fields (OAuth refresh tokens, Register Numbers, NeoPAT IDs) are encrypted at rest using AES-256 (cryptography Fernet) with a master key.
- [x] **SEC-03**: Temporary email attachments are processed entirely in memory or temporary volumes and deleted immediately upon task completion (Data Minimization).
- [x] **SEC-04**: System generates security audit logs tracking OAuth events, watch renewals, email processing, and notification delivery, storing metadata only.
- [x] **SEC-05**: Observability setup implements structured JSON logging, health checks, and Prometheus metrics.

### Reminder Engine (REM)

- [x] **REM-01**: Scheduler sends automated alerts 24h, 6h, and 1h prior to parsed application or event deadlines based on priority policies.

## v2 Requirements

### Interactive Chatbot (CHAT)

- **CHAT-01**: Telegram Bot accepts interactive commands for status checks, registration updates, and history review.
- **CHAT-02**: User can pause or mute notifications directly from Telegram.

### Analytics (ANLT)

- **ANLT-01**: User dashboard displays success rates, statistics, and a timeline of placements.

## Out of Scope

| Feature | Reason |
|---------|--------|
| Resume Analyzer | High token complexity and unnecessary for email alert priority. |
| Job Recommendation System | Excluded to keep the notification engine simple and focused. |
| Social Features | Kept out to maintain privacy for students' personal placement outcomes. |
| Multi-College Support | Avoids template bloat; focused solely on VIT email formats and student IDs. |
